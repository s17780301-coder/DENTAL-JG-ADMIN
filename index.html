Gestores y claves de acceso

Los usuarios deben tener cuentas individuales. No se muestran ni se almacenan contraseñas en texto plano.

Las cuentas se crean de forma segura en Supabase Authentication. Asigna el rol en app_user_roles y vincula el gestor en collection_managers. Esta vista evita crear claves manuales inseguras desde el navegador.

Para activar este módulo se requiere confirmar el esquema real de roles/gestores de la base de datos.
