DENTAL JG — PANEL ADMINISTRATIVO MULTI-CLÍNICA
==============================================

QUÉ INCLUYE ESTA VERSIÓN
- Panel web adaptable a teléfono, tableta y computadora.
- Inicio de sesión con el usuario de Supabase que ya tienes.
- Selector para ver Todas las clínicas o una clínica en particular.
- Pantalla “Clínicas” para agregar clínicas directamente desde el panel.
- Las clínicas se guardan en Supabase y se sincronizan entre dispositivos.
- Los indicadores, la lista de pacientes y el historial de pagos se filtran por la clínica elegida.
- Conserva los nombres de clínica que ya aparecen en los registros existentes.
- Resumen de pacientes, cobranza, saldos pendientes y pacientes al corriente.

IMPORTANTE
Esta versión agrega el catálogo de clínicas y el filtro. Los listados de pacientes y pagos siguen siendo de consulta; todavía no incluye formularios para dar de alta/editar/eliminar pacientes ni registrar abonos desde el panel. Tampoco conecta automáticamente la app Android DENTAL JG V9.4: para sincronizar sus datos habrá que actualizar esa app aparte.

ACTUALIZAR TU PROYECTO SUPABASE (NECESARIO UNA SOLA VEZ)
1. Descarga y descomprime este ZIP.
2. Entra a https://supabase.com/ y abre el mismo proyecto que ya usa DENTAL JG.
3. En el menú lateral abre SQL Editor y crea una consulta nueva.
4. Abre el archivo supabase_schema.sql de esta carpeta, copia todo el contenido y pégalo en SQL Editor.
5. Pulsa Run. Este script está preparado para conservar los pacientes y pagos existentes; crea la tabla de clínicas y registra nombres de clínica ya usados.
6. Vuelve al panel y recarga la página. Inicia sesión y entra en “Clínicas”.
7. Escribe el nombre de una clínica y pulsa “Agregar clínica”. Después puedes elegirla en el selector superior.

PUBLICAR LOS CAMBIOS
Debes publicar los archivos actualizados de esta carpeta en el mismo sitio donde está alojado el panel. Si lo publicas en GitHub Pages, reemplaza los archivos del repositorio con los de esta carpeta, conservando config.js y sus valores actuales. No subas claves secretas.

CONFIGURACIÓN Y SEGURIDAD
- config.js contiene la URL del proyecto y la clave pública publishable/anon. No reemplaces esos valores por una clave service_role/secret.
- El acceso depende de Supabase Auth y las políticas RLS.
- Las políticas incluidas permiten administrar los datos a cualquier usuario autenticado. Crea cuentas solo para personal de confianza.
- No uses información real de pacientes hasta revisar quién tiene acceso y confirmar las políticas de seguridad.
